    IBM Z Integration

    LUCID-Z is designed to run natively on IBM Z / LinuxONE using the s390x architecture. When z/OS ML Scoring is configured and reachable, inference is offloaded to IBM Watson Machine Learning for z/OS, leveraging the Telum AI accelerator for hardware-assisted DDoS detection.
